# 来源与改编说明

更新日期：2026-09-17。

## 事实范围

本章八组人机对话均为教学案例，用于比较不同表达和反馈带来的变化。案例中的执行结果与效果描述未经实际运行验证，不能当作操作记录或效果保证。其中“案例好于说明”的对话用来比较案例携带的信息，不是通用的 Linux 文件筛选方案。

## 原始资料

概念和案例来自 Henry_He《AI 时代的思维框架》[主篇](https://linux.do/t/topic/2538870)及[补充篇](https://linux.do/t/topic/2588749)。参照资料库合并正文及原文配图，原文的“先推理后结论”同时对照用户提供的两张截图。

## 本版处理

- 八个模块依次为语义漂移、特征纠缠、显式配平、隐式提纯、案例好于说明、引导采样与回滚、先推理后结论、语义退火。
- 每个模块的 A/B 两条路线均配有一张 GIF 与一张对话 PNG，共 16 张 GIF 与 16 张对话 PNG，按“GIF → 对话 PNG → 解释”纵向排列。对话 PNG 由 `素材/对话.json` 中保存的全文生成。
- `素材/对话.json` 是 16 组对话图片的文字真源，保留全部人机对话轮次，包括工具命令与返回内容；正文 Markdown 负责组织文章与解释。PNG 是从 JSON 确定性派生的渲染结果，不是截图冒充的原作者配图。修改对话文字应改 JSON 后重新生成图片。
- 语义漂移第一组（drift-a）按原作者 40GB 日志案例完整转录，含工具命令与错误返回；第二组（drift-b，82GB 清理结果）是课程构造的另一段独立纠偏教学对话，不是 40GB 案例的后续记录，也不是原作者成功实测。正文已用一句话说明换用独立示例。
- 特征纠缠两组对话恢复自旧课程“特征解耦”教学材料（注册接口案例），对话为课程构造；概念名与性质解释采用本版“特征纠缠”的表述。
- 显式配平 B 组末尾的 HTML 片段转录自原作者配图中的示例代码，原图即以省略号截断，未补造完整代码。
- 隐式提纯、先推理后结论、语义退火各两组对话为教学示例，保留自原作者配图的转录；本课程未做实际运行验证，无法确认原作者是否运行过。
- 案例好于说明两组对话：A 组（分散文字要求）为课程既有对照文字；B 组（一行案例）含 `ls -al | grep "\.log$"` 管道命令及解释，为教学示例，不作为通用 Linux 操作推荐。
- 引导采样与回滚 B 组末尾的代码片段转录自原作者配图中的 AI 回复，原图即以省略号截断。
- 先推理后结论使用用户截图中的“三打白骨精”原话；其错误回答明确置于对比案例中。
- 原作者经验框架、案例中的效果承诺与课程实测分别处理；不把地形、退火或语义纯度当作实测内部机制。
