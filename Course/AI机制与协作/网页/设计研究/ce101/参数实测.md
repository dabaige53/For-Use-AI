# CE101 页面参数实测

测量日期：2026-09-17。参考：[首页](https://ce101.ifuryst.com/)、[提示词技术文章](https://ce101.ifuryst.com/core-tech/prompt-engineering-techniques)。

本记录是参考站的测量结果，不是本地页面已完成的实现声明。此次不修改课程正文、GIF 或网页实现。

## 测量口径

- 通过浏览器读取真实 DOM、`getComputedStyle()` 和 `getBoundingClientRect()`；用视口控制验证断点。
- 单位均为 **CSS px**，根字号 16px。坐标从网页视口左上角开始，不含浏览器标签栏、地址栏。
- 桌面基准为 1440 × 900；另测 390、640、768、1023、1024、1170、1279、1280、1600、1920 宽度。所有这些宽度未检测到文档横向溢出。
- 样式使用站点当前浅色主题、无公告条状态（`--banner-height: 0px`）。开启公告、深色模式会改变相关参数。
- 浏览器缩放、设备像素比、截图缩放会改变截图中的像素距离。不能把截图图片宽度直接当成 `innerWidth`。
- 小数来自布局的亚像素计算，表格保留两位小数。H3 在所测两页无正文实例，单独标记为 CSS 规则值。

## 页面结构与宽度公式

### 外层

`#navbar` 后的主布局外盒 `max-width:1472px; margin-inline:auto; box-sizing:border-box`。

- ≥1024px：左右 padding 各 32px，内部 flex，左导航占 288px。
- <1024px：左右 padding 各 16px；正文盒另有左右各 4px，所以最终正文距视口边缘 **20px**。
- 顶栏自身占满视口，内部也受 1472px 上限约束，但桌面内部左右 padding **48px**，不是主内容的 32px。

### 桌面正文的实际组合

```css
/* 参考站相关布局规则，按其层级保留 */
.outer { max-width: 1472px; margin-inline: auto; padding-inline: 32px; display: flex; }
#sidebar { width: 288px; flex-shrink: 0; }
#content-container { flex: 1; min-width: 0; }
#content-container > div { display: flex; flex-direction: row-reverse; gap: 48px; padding-top: 40px; }
#content-area { flex-grow: 1; margin-left: -48px; padding-left: 91.2px; padding-right: 4px; }
/* >=1280px 才参与布局 */
#content-side-layout { width: 304px; }
#table-of-contents-layout { width: 304px; padding-left: 40px; }
#table-of-contents { width: 264px; }
```

`#content-area` 的 91.2px 来自 `5.7rem`。因此不能把左右栏和正文简单写成三个固定宽度加统一 gap。

设 `V` 为视口宽度，`C=min(V,1472)`，`M=max(0,(V-1472)/2)`：

| 状态 | 正文文字左边界 | 正文可用宽度 |
| --- | --- | --- |
| V < 1024 | 20 | V − 40 |
| 1024 ≤ V < 1280 | M + 363.2 | C − 399.2 |
| V ≥ 1280 | M + 363.2 | C − 751.2 |

完整三栏时：左导航高亮盒右边界到正文文字左边界 **75.2px**；正文文字右边界到右目录文字左边界 **92px**（正文右 padding 4 + 栏 gap 48 + 右目录左 padding 40）。

## 正文标题与阅读节奏

字体声明优先顺序：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, sans-serif`。站点实际 computed 栈因回退拼接出现重复。中文最终字形由系统回退决定，不把 Inter 误写成内置中文字库。

| 文本 | 字号 | 行高 | 字重 | 字距 / 间距 |
| --- | ---: | ---: | ---: | --- |
| 分类 Eyebrow | 14 | 20 | 600 | 下 margin 10 |
| H1 ≥640px | 36 | 40 | 600 | letter-spacing −0.9px |
| H1 <640px | 30 | 36 | 600 | tracking-tight，−0.025em |
| 导语 | 18 | 28 | 400 | 上 margin 8 |
| 正文 | 16 | 28 | 400 | 段落一般上下 margin 20；首段和紧接标题的段落上 margin 0 |
| H2 | 24 | 32 | 600 | 上 margin 36、下18；首个 H2 上0；字距−0.6px |
| H3（CSS规则） | 20 | 28 | 600 | 上32、下14；字距−0.5px |
| 列表条目 | 16 | 28 | 400 | 上下 margin8，左 padding6 |
| 引用块 | 16 | 28 | 400 | 上下 margin25.6，左 padding24 |
| 代码块文字 | 14 | 24 | 400 | paperMono + monospace 回退 |
| 表格（文章实例） | 14 | 20 | 400 | 上下 margin28；所测 td padding0 |

桌面顶部垂直链路（1440px 首页、一行 H1）：

```text
顶栏 y=0…64
正文区上 padding 40 → header y=104
header 内上 margin 2 → eyebrow y=106，高20
eyebrow 下10 → H1 y=136，高40
导语上8 → lead y=184，高28
正文上32 → 首 H2 y=244，高约32
H2 下18 → 第一段 y≈294
```

`#content` 下 margin 56px。文本高度随着内容与换行变化，不能把首页某个 y 坐标当成所有文章的固定高度。

## Copy page 与标题锚点

- Copy 容器最小宽 156px；H1 所在 flex 行 gap8px，垂直居中。
- **容器查询** `@container page-header (width >= 520px)`：复制操作与标题同行；不足 520px 时移到导语下方，上 margin12px。不是简单的手机视口断点。
- 左按钮实际约121.54px，右下拉约34px，整体约156px；高度34px。
- 左按钮 padding6px 12px，左右两端组合成12px圆角；1px gray-200 边框；白底，无常态投影。
- 文字14px /20px、500；复制图标16px；下拉图标12px；文字与图标 gap8px。
- H2 左侧锚点占40px，margin-left:-40px，常态 opacity0，标题 hover 或键盘 focus 时 opacity1。没有占用正文第一行宽度。

## 右目录

- 仅 ≥1280px 显示，侧栏 sticky top104px；可用高 `calc(100vh − 128px)`。
- 外盒304px，左 padding40px，文字区264px。
- 内层 margin-top:-40px，再由滚动内容 padding-top40px 抵消；可见目录标题在 y104，不能照 DOM 外盒 y64 来摆放文字。
- 文字14px /24px、400；每个链接上下 padding4px，一行项32px。
- 所测提示词文章的“3.1.1”等均实际为 H2，右目录 padding-left0；不能仅依据编号小数层级推断 DOM 为 H3 或加缩进。
- 高亮主题蓝，±0.15px text-shadow。参考站所测目录没有本地页面那条常驻蓝色竖线。

## 搜索弹层

实测桌面空搜索状态：宽640px（max-width640px），圆角20px，白底；1440×900时 x400、y54。空状态高62px，**不是结果出现后的固定高度**。

- 外层布局与自身 margin-top6px 共同决定位置。
- 输入字号16px /24px、500，字距−0.2px；输入区高36px，左padding30px。
- 结果列表 padding-top6px、左右6px。
- 1px深色6% ring；三层阴影：`0 57px 34px rgba(0,0,0,.01)`、`0 25px 25px rgba(0,0,0,.02)`、`0 6px 14px rgba(0,0,0,.02)`。
- 打开动画250ms，关闭150ms；opacity 与 scale(.96→1)，曲线`cubic-bezier(.22,1,.36,1)`；reduced-motion 禁用。
- 内容相关的结果数量、结果项高度、加载和错误态不作为固定尺寸；本轮未提交搜索关键词到外站。

## 实现时的准确依据

1. 先按真实 DOM 层级复现宽度规则，再调整组件。不可继续叠加视觉猜测的 max-width 和 gap。
2. 使用 CSS 视口宽度对齐验收；分别检验1023/1024、1279/1280，避免只看一张桌面图。
3. 将正文、header外盒、右目录外盒和右目录文字区分别测量，避免误把padding算进正文宽度。
4. 同行复制按钮按520px容器查询处理，长标题自然折行，不用 padding-right 硬挤。
5. 引用站点骨架与真实尺寸；课程自己的名称、七篇目录和正文长度决定内容差异。
6. 用户要求的收起把手、整块对话底色与GIF展示属于课程附加交互，不是参考站原有参数。
