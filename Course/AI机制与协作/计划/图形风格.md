# 图解局部风格

各板块配图采用课程正文内嵌图的局部样式，不修改全局 `diagram-design` Skill 或任何 profile。

- 画布：纯白 `#FFFFFF`，无纹理、渐变、阴影。
- 主色：深蓝 `#163A5F`；强调蓝 `#1769AA`；浅蓝 `#EAF4FB`；次级线 `#7A9AB8`；正文 `#18324A`；辅助文字 `#536B80`；分隔线 `#C9D8E5`。
- 字体：`PingFang SC`, `Noto Sans CJK SC`, `Microsoft YaHei`, sans-serif；不加载远程字体。中文正文最小 16px，标题 28px。
- 形状：圆角 8px 以内；节点靠边框、留白和层级区分；不使用装饰图标与 emoji。
- 连线：优先水平或垂直的正交路径，箭头不穿过非端点节点；同一节点多线时分离附着点。
- 尺寸：正文图默认 `doc-inline`（960×600）；内容密度需要时使用 `doc-wide`（1280×600）。标题与主要对象保留边距，底部图注在画布内。
- 强调：每图只突出一至两个关键对象或关键路径。图例仅在编码不能由图面直接理解时出现。
- 交付：图形内容由 `工具/rebuild_diagrams.py` 维护，重建各板块 `配图/` 中的自包含 HTML 与同名独立 SVG；两者均含 `<title>` 与 `<desc>`，无脚本和外部依赖。
