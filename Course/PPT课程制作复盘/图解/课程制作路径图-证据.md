## 编辑与验证

- 画布中的文字、形状、箭头和 UI 示意是 Excalidraw 原生元素，可编辑；六张原图作为内嵌图片，可移动与缩放，图片内文字不是原生文本。
- 四个模块分别分组，可整体移动；需要改局部时进入组内或取消分组。关系箭头绑定到流程节点。
- 已逐模块渲染并查看，修正穿过旁注的连线和图片旁的文字重叠；最终整图再次导出。主预览 PNG 显示完整画布与全部图文；四张模块图只是同一画布的局部导出。
- Excalidraw MCP 已用于显示图形元素。桌面工具禁止读取 Codex 窗口，无法直接截图验收 MCP 小组件；视觉核验使用同一组元素经 Excalidraw 官方导出 API 得到的本地预览。
- 本次仅制作图解与证据文件，没有修改课程正文、PPT、视频，也没有提交 Git。
