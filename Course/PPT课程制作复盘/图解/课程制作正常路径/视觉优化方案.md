# 课程制作正常路径：视觉优化方案

## 目标与范围

保留已确认的四条制作线、步骤及依赖关系，重做画面的组织方式与组件内部细节。只优化正常路径，保留正常调整回路。

成品仍是一张可缩放的 Excalidraw 画布。远看能辨认四条线和产物交接，近看能读懂每次操作、判断与产物。来源、节点编号和状态核验保留在来源文档，不作为画布旁注。

## 一、整体版式

### 总览＋四个制作区域

顶部用紧凑总览展示地形、视频、网页、PPT 的关系。总览只保留区域名称、产物缩略图和交接关系，不重复各区的完整流程。

下面按地形、视频、网页、PPT 展开，每个区域有明确的阅读入口和主要产物。四区分开阅读，跨区用产物名称接续，避免横跨整张画布的长线。

取消每段固定的左右等分布局，改用三种组合：

- **主图＋细节**：一张主要画面占约三分之二，旁边安排局部放大、参数或操作。
- **横向推进**：用于同一段内容的连续变化、选定图进入页面等有明确先后的关系。
- **平行汇合**：用于不同来源的内容、独立的接入支线；汇合之前保持分支清楚。

比例按内容调整，不把三种组合变成新的固定格子。

### 阅读层次

1. 区域标题：说明在制作什么。
2. 主要画面：看见输入、操作或产物。
3. 关系：看见顺序、变化、对应或交接。
4. 局部细节：支持判断的内容、参数、图形变化。

标题不再承担整段解释。大段说明不放进画布底部。

## 二、视觉语言

| 项目 | 设计方式 |
|---|---|
| 背景 | 白底，以留白区分区域；不为每块内容加大外框 |
| 轮廓 | 深灰手绘线，保持适度不规则；图片框和分组线从简 |
| 区域识别 | 地形浅蓝、视频浅紫、网页浅绿、PPT 浅橙；用于局部底色和细线 |
| 卡片 | 用于独立对象、协作阶段、候选或产物；以淡色错位底板形成层次 |
| 虚线 | 区分引用关系、局部分组和反馈回路；不作为所有框的装饰 |
| 下划线 | 标出阶段标题或采用对象，避免整段文字都被强调 |
| 便签 | 只保留与判断相关的短内容，例如“采用这张”“保留轨迹”；没有事实依据就不添加 |
| 箭头 | 从具体对象连接到具体对象；线旁只写交付物或变化，不重复标题 |
| 图片 | 原始素材作主体；放大区域从同一素材中截取，保留完整图与局部的对应 |
| 文字 | 阶段标题约 30–36，主体约 24–28，图内标签约 20–22；按实际缩放检查可读性 |

细节来自内容：真实文章片段、画面状态、参数、交接对象。阴影、便签和手绘线只辅助组织，不靠装饰增加数量。

## 三、逐段视觉方案

### 地形与教学对话

| 段落 | 主体结构 | 要展开的细节 | 文字保留 |
|---|---|---|---|
| 收集文章、建立映射 | 材料集合＋概念到图形映射 | 使用原文标题和一段短内容；圈出需要图形表达的概念，分别连到地形、小球、轨迹。具体映射须对照文章核实 | 原文关键词、图形名称、映射动作 |
| 构建 HTML 原型 | 主图＋界面标注与局部放大 | 放大原型主体；把运行、重置等操作入口和图形变化放在同一视野内；参数区有真实界面时使用真实界面 | 参数或操作名称；此处保留“用户／AI／产出” |
| 操作与调整 | 同一演示的连续状态＋反馈回路 | 从现存演示中取得同一过程的几个状态，标出小球或轨迹的变化；与原文关联。若缺少历史前后版本，不伪造“修改前后” | 对照对象、调整项、返回位置 |
| 交付演示 | 教学对话与地形并列＋交接出口 | 放大一组对应的教学对话和地形画面，让两者通过颜色、位置或引线关联；引出网站和 PPT 两个使用出口 | 教学内容、HTML 演示、交付去向 |

本区视觉重点是“文章含义如何落实到可操作画面”，不能只展示漂亮地形。

### 视频制作

| 段落 | 主体结构 | 要展开的细节 | 文字保留 |
|---|---|---|---|
| 参考还原与方法提炼 | 参考拆解板＋本地产物 | 区分参考来源、本地还原和提炼的方法；本地视频帧不能冒充原片。内容、图形、实现三个拆解出口对应实际资料 | 参考名称、取得的资料、提炼结果 |
| 三个 skills | 共用方法＋三份职责卡 | 每张卡明确输入与输出，分别连到文章、单镜动画、整片制作；使用不同内容缩略图，避免三个相同空框 | skills 名称、职责、应用环节 |
| 内容准备与镜头安排 | 文章片段＋层级拆分 | 用输入输出文章的一段内容展开成镜头主题；让读者看见“哪段内容被安排到哪个镜头” | 文章关键词、镜头主题 |
| 分镜到视频 | 分镜总览＋连续关键帧＋成片 | 十二格图作为索引，选取能体现变化的相邻格放大；连到现存成片中的对应画面。素材不匹配时不画一一对应关系 | 新增对象、状态变化、产物名称 |

本区主图应是放大的连续画面，不能让十二格缩略图独自承担全部讲解。

### 课程网页

| 段落 | 主体结构 | 要展开的细节 | 文字保留 |
|---|---|---|---|
| 多条内容线整理 | 四条内容泳道＋真实产物预览 | 其他文章、四象限、地形、输入输出分别带文章或图形预览；表现从原始材料到供网站使用的内容 | 材料标题、整理动作、结果 |
| 内容与网站参考结合 | 汇合关系＋网站主体 | 内容依据、文章要求、网站参考各自接入；以网站页面为主图，标出正文、图形、交互的位置。原始参考与实际网站不得混用截图 | 来源名称、页面区域、开发动作 |
| 查看与调整 | 网站局部＋明确回返 | 从正文、图形、交互中选择可见对象，连接到相应调整位置；不使用一列抽象检查框代替页面 | 检查对象、调整去向、网站产物 |

本区要看见“内容进入网页后如何被组织”，而不只是多条线汇入“网站”二字。

### 现场 PPT

| 段落 | 主体结构 | 要展开的细节 | 文字保留 |
|---|---|---|---|
| 演讲要求与大纲 | 要求卡＋内容骨架＋页面缩略图 | 已确认的演讲要求连到大纲层级；每个主章节配一张相关内容缩略图，不重复写“确定重点” | 要求、章节、讲述关系 |
| 生图、确认 UI、嵌入 | 选定图为主体＋页面承接 | 有可核实的同目标候选时才做候选比较；否则直接展示选定图及接入关系。放大能说明选定内容的局部，不填造候选 | 采用对象、确认动作、页面结果 |
| 视频与地形接入 | 样例确认＋内容嵌入 | 视频与地形有各自预览；展示它们在 PPT 内的播放或操作区域，而非只写“查看效果” | 原型、确认、接入 |
| 四象限接入 | 图形主体＋局部操作＋汇合 | 坐标图应可辨认；放大任务点或图形状态，表现 PPT 中的呈现与操作。维度按所选版本读取 | 图形内容、操作入口、接入 |
| 整体回顾 | 页面缩略带＋局部检查＋回返线 | 将内容衔接、页面一致性和演示配合落到页面或组件上；不添加无依据的问题批注 | 检查位置、调整对象 |
| 讲稿与交付 | 页面、讲述、操作三轨对应＋交付组合 | 以真实页面作定位，展示需要组织的讲述与操作关系。没有核验过的讲稿不填成真实摘录，不加完成标记 | 讲稿、衔接、演示安排、交付组成 |

PPT 区的主视觉是“选定表达与页面中的使用效果”，两条接入支线分别呈现后汇合。

## 四、文字处理规则

### 留下

- 具体对象：文章标题、镜头主题、页面内容、工具或 skills 名称。
- 具体动作：收集、映射、生成、选择、确认、嵌入、调整、交付。
- 有助于读图的短标签：小球、轨迹、播放、重置、输入、产出。
- 能说明真实选择或要求的短语，不虚构评价与完成状态。

### 删除

- 节点编号、来源说明、截图说明、组件名称和制作自述。
- 与标题重复的副标题、总结句和“这一部分说明……”类文字。
- “逐步、进一步、直接、完整、清楚”等不增加具体信息的修饰。
- 占据图形空间却没有动作、对象或关系信息的便签。

必要的证据边界放在来源文档中。画布标题与关系本身仍须准确，不能因删注释而把示意或未完成事项画成历史事实。

## 五、制作与检查顺序

1. **先重做地形区。** 用原文、教学对话和演示画面做出“映射—操作—变化—交付”的完整视觉样段。
2. 检查主图比例、图内文字与手绘组件的协调关系，再展开视频区。
3. 制作网页汇合区与 PPT 区，采用各自合适的布局，不机械复制地形排法。
4. 统一颜色、字体、连接线及交接出口；压缩清理文字后留下的无效空白。

每区按以下标准检查：

- 不读段落说明，也能看见主要动作和交付物。
- 至少有一个值得放大的内容主体，能读到实际细节。
- 相邻画面有可解释的差异；并列对象不被误画成时序。
- 连线不穿过文字和图片，回返线落到具体修改位置。
- 图片、文字和标注形成关系，不是把图片贴在步骤旁边。
- 原生文字、形状、箭头可编辑；图片使用原始素材，避免整区栅格化。
