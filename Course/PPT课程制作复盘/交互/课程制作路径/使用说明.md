# 课程制作路径交互图

双击 `启动交互图.command` 打开。保留 Mermaid 原始布局、分组与连线，使用 Panzoom 增加拖动与缩放。

- 点击节点，在节点旁打开画布内浮卡；画布保持原宽度。
- 请求与回复带角色图标，图片附在对应对话下方。多张图片在浮卡内堆叠，鼠标滚动、左右拖动或方向键切换；点击当前图片单独放大。
- 大图弹窗只显示当前图片，按 Esc 关闭后回到原浮卡。浮卡只展示关键对话摘录；文档、视频和网页以链接打开。
- 已核对的 21 个节点使用真实对话；其余节点保留已有材料，不补写对话。
- 核心文章使用摘要、图片及可展开要点；已有图片使用图片堆叠；辅助 Skill 和文件入口使用紧凑链接。采用资料放在对话上方，形成资料放在下方。
- 拖动或双指滑动平移，双指捏合或 Ctrl＋滚轮缩放。画布不显示顶部工具栏或底部说明。
- 按 Esc 或关闭按钮收起浮卡。
- 材料链接在新标签页打开，浮卡不嵌入文档全文、视频播放器或交互网页。

主路径来自 `../../图解/课程制作主路径.mmd`。材料由 `制作弹窗内容.py` 生成到 `节点材料.json`，引用项目原文件。当前为本地版本，运行期间保留终端窗口。

修改画布交互后在本目录运行 `pnpm run build`。演讲编排练习是学员练习模板，不代表历史演讲稿已经完成。

对话映射位于 `节点对话.json`，通过 `整理节点对话.py` 从原始记录提取；每条保留文件名与消息编号。更新后重启预览服务。堆叠图片交互位于 `image-stack.js`。

下一轮内容与网页实现以 [课程制作路径-内容与网页制作规格](课程制作路径-内容与网页制作规格.md) 为准；当前网页仍为迁移前版本。
