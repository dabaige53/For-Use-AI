# 课程制作路径交互图

双击 `启动交互图.command` 打开。保留 Mermaid 原始布局、分组与连线，使用 Panzoom 增加拖动与缩放。

- 点击节点，在节点旁打开画布内浮卡；画布保持原宽度。
- 请求与回复带角色图标，图片附在对应对话下方。多张图片在浮卡内堆叠，鼠标滚动、左右拖动或方向键切换；点击当前图片单独放大。
- 大图弹窗只显示当前图片，按 Esc 关闭后回到原浮卡。浮卡保留解释制作决策的对话细节；文档、视频和网页以链接打开。
- 47 个节点均使用按流程动作整理的用户与 AI 对话；文案经过改写，不是逐字历史记录。讲稿等待完成内容明确保留待制作状态。
- 采用资料位于对话上方，形成资料位于下方；图片只来自消息的显式附件配置。不自动补图、补链接。
- 原始文章显示名称、来源与用途；辅助 Skill 使用紧凑链接。对话内短链接可直接打开对应材料。
- 拖动或双指滑动平移，双指捏合或 Ctrl＋滚轮缩放。画布不显示顶部工具栏或底部说明。
- 按 Esc 或关闭按钮收起浮卡。
- 材料链接在新标签页打开，浮卡不嵌入文档全文、视频播放器或交互网页。

主路径来自 `../../图解/课程制作主路径.mmd`。材料由 `制作弹窗内容.py` 生成到 `节点材料.json`，引用项目原文件。当前为本地版本，运行期间保留终端窗口。

修改画布交互后在本目录运行 `pnpm run build`。演讲编排练习是学员练习模板，不代表历史演讲稿已经完成。

弹窗内容位于 `节点对话.json`，由 `整理节点对话.py` 从制作规格读取改写文案，再合并 `节点多轮对话.json` 中核对过的多轮片段，结合显式资料与附件归属生成；记录依据保留在维护字段。更新后重启预览服务。堆叠图片交互位于 `image-stack.js`。

下一轮内容与网页实现以 [课程制作路径-内容与网页制作规格](课程制作路径-内容与网页制作规格.md) 为准；47 个节点的弹窗内容已按规格迁移。

同一线程的多轮讨论按顺序连续展示，向下滚动阅读。只有明确使用不同 `threadId` 的线程才显示 1、2、3… 圆形切换按钮，数字旁不显示说明文字。未标记线程的片段按同一线程合并；图片保留在所属消息下方。
