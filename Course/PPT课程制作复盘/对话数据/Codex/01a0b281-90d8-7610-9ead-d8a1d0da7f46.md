来源：`rollout-2026-09-18T11-13-50-01a0b281-90d8-7610-9ead-d8a1d0da7f46.jsonl:L14`

我建议采用 **“极简演示舞台”**：以留白、清晰排版和稳定的布局承载内容，让视频、3D 地形图、数据图和画布成为视觉中心。

你这类培训的重点是让听众在“听讲、观察、操作”之间顺畅切换。**界面越安静，内容的变化越容易被注意到。**

### 1. 视觉风格：暖白底、深灰文字、一个强调色

整体可以接近简洁的编辑排版：大标题、短句、宽留白，少用边框和装饰。

| 元素 | 建议 |
|---|---|
| 背景 | 暖白 `#F7F8FA`，比纯白稍柔和 |
| 正文 | 深灰 `#20242C`，投影时保持清晰 |
| 强调色 | 蓝色 `#356DF3`，用于重点、选中状态和主要操作 |
| 辅助色 | 灰色用于说明；数据颜色按含义固定使用 |
| 字体 | 中文用苹方或思源黑体，整套保持一致 |
| 容器 | 少量圆角、极淡边框，尽量不加阴影 |
| 动效 | 简短淡入和必要的状态过渡，避免连续装饰动画 |

3D 地形图或视频适合深色环境时，可以让**内容区域切换为深色舞台**，外围控件的位置与样式保持一致。

### 2. 页面结构：一页一个重点，一个主要操作

建议只做四种页面模板，用它们组成整场培训：

| 页面类型 | 布局方式 | 适用内容 |
|---|---|---|
| **观点页** | 大标题＋一句解释＋一张主图 | 引出问题、解释概念、总结 |
| **演示页** | 内容占据大部分屏幕，旁边或下方留一句观察提示 | 视频、3D 地形、网页演示 |
| **探索页** | 左侧约 25% 放问题和控制项，右侧约 75% 放交互内容 | 参数调整、四象限图、情景比较 |
| **共创页** | 画布接近全屏，工具集中在一条简短工具栏 | 分类、拖拽、标注、讨论 |

**不要把视频、图表、画布同时塞进一页。** 即使它们属于同一主题，也可以按“先观察 → 再操作 → 最后归纳”分步出现。

例如讲四象限时，先展示坐标轴和问题，再让大家判断案例位置，最后揭示解释。互动由教学问题推动，界面负责把每一步呈现清楚。

### 3. 交互内容：默认简单，需要时再展开

不同内容应有各自最清楚的操作方式：

- **视频**：用干净的封面和播放按钮，播放前显示一个“带着什么问题看”的提示。
- **3D 地形图**：初始视角先把重点展示出来，提供“自由探索”和“重置视角”；高级参数收进设置。
- **四象限图**：轴名称始终可见；点选案例后显示解释，颜色承担明确含义。
- **画布**：常驻工具控制在选择、画笔、便签、撤销、清空等少数操作，并明确区分“演示”和“编辑”状态。

嵌入网页尽量隐藏多余导航，让听众感到自己一直处在同一套培训里。

### 4. 播放界面：平时隐去，操作时出现

主画面只保留必要信息：小号章节名、页码或细进度条。上一页、下一页、目录、全屏等控件，在鼠标靠近底部时显示。

这里有一个很关键的细节：**操作画布或 3D 图时，滚轮和方向键不应该误触翻页。** 进入交互后，应有清楚的“返回演示”入口。

如果主要用于现场投影，建议以 16:9 为主，正文从 28–32 px 起步，再按实际观看距离调整；灰色说明文字也要有足够对比度。

我的首选方案是：**暖白底＋深灰字＋单一蓝色强调，四种固定版式，交互内容可全屏展开。** 简约感来自统一与克制，互动感来自内容本身。喵～
