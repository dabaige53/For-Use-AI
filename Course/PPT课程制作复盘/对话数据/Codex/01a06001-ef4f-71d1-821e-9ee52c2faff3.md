- 实线轨迹：表示连续 token 的采样序列。
  - 是多个 token 落点之间的序列连接。
  - 不是一颗球长期运动的物理轨迹。
  - 线段只在对应地形已经形成后出现。

- 词元标签：绑定一组 token 球，而不是绑定大球。
  - 标签出现；
  - 对应 token 球落下；
  - 地形发生变化；
  - 下一颗采样球才响应。

- 不是一颗球创造全部地形；
- 是多个历史 token 共同塑造地形；
- 地形影响下一颗 token 的采样；
- 每颗新 token 又会加入历史，继续改变后续空间。
