# Course 演讲模式

这是一套 10 页、固定 16:9 的浅色 HTML 幻灯片，不替换现有文章阅读器。地形与散点图是同一文档中的原生 Canvas / SVG，不使用 iframe，也没有复制原网页的目录、侧栏、房间或旧插图。源文件位于本目录，构建产物是 `../dist/slides.html`。

## 使用

在 `Course/网页` 中执行：

```sh
node scripts/build-slides.mjs
```

这个命令只构建幻灯片，使用 Node 内置模块，不需要安装新的前端依赖。完整的 `pnpm build` 会先构建原文章阅读器，再构建幻灯片；原来的 `pnpm check` 仍检查文章阅读器。

用浏览器打开生成的 `dist/slides.html`，或在 `pnpm preview` 后访问 `/slides.html`。不要直接打开 `presentation/deck.html`，它是包含构建标记的模板。CSS、JavaScript、任务数据会全部内联到产物中，不依赖 CDN、远程字体或原演示网页；已选择的本地视频只在当前浏览器中播放。

左右方向键或 PageUp / PageDown 翻页，F 全屏，N 查看当前页讲者备注，G 总览。地形页可以拖动旋转、滚轮缩放、空格播放或暂停，也可以逐步播放；选中画布后 R 恢复视角。四象限的独立深色演示点可以拖动，选中后方向键微调，Shift + 方向键加大步长。原始 45 项任务不会被拖动修改。系统开启“减少动态效果”时不自动播放地形。

## 接入你的本地视频

仓库 `.gitignore` 排除了 MP4 等大媒体，因此远程代码并不包含你的本地视频。最简单的方式是在第 03、04 页分别点击“选择本地视频”。文件不会上传，也不会在页面刷新后自动恢复授权。

构建时可显式指定视频。相对路径按 `Course` 目录解释；绝对路径也可用：

```sh
COURSE_LLM_VIDEO="/absolute/path/model.mp4" \
COURSE_IO_VIDEO="/absolute/path/io.mp4" \
node scripts/build-slides.mjs
```

未指定时，只查找现有渲染脚本中已经确认的完整输出：

- 第 02 篇：`大语言模型简要说明/生成/mini-llm-zh-480p-0000-0659.mp4`。
- 第 03 篇：`AI的输入与输出/生成/<批次>/AI_IO_480p_silent.mp4` 或 `AI_IO_1080p_silent.mp4`。只在恰好找到一个完整预览时自动采用；多个候选不擅自选最新，改用环境变量或页面选择器。

已找到的视频复制到生成目录 `dist/media/`。分发已接好视频的版本时，应同时分发 `slides.html` 与 `media/`，不要只有 HTML。构建目录是可重新生成的产物；重新打包前运行完整 `pnpm build`，避免带入旧媒体。

这些默认文件是预览输出，并不因此成为已核验的有声成片。已知输入输出动画的正式文章记录的是静音预览，旁白和有声制作尚未完成。播放器不会伪装成已附带视频；无文件或解码失败时显示选择提示。

## 内容与来源边界

散点数据在每次构建时直接读取 `Course/06-行动选择与投入控制/素材/七页演示内容.json` 的 `tasks`；保留 id、text、investment、alignment、reason、cat。分值是教学情境比较，50 只是排版分界，不是实测评分或硬性门槛。坐标重合不做随机抖动，通过任务选择器可访问所有记录。

地形核心移植自 `Course/04-需求表达与反馈闭环/交互/思维地形.html`，对应源 blob `4085e70d5df13dacf95589aa16752e53644f822a`。地形是教学比喻，不是模型内部思维链观测；案例也不代表真实执行。第二篇视频的原理来源与改编署名保留在讲者备注中。

`dist/slides-sources.json` 记录任务源摘要与媒体接入状态，便于核对。任务数量或字段变化会让构建明确报错，避免悄悄沿用失效的“45 项”文案。
