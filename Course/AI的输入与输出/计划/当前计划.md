# 当前计划

当前结构为三个连续主镜头，每个主镜头一份 JSON、一张十二格演进分镜板。此前 S01—S08 是内部动作段，不是八张最终分镜板。

| 主镜头 | 内容 | 状态 | 原动作段对应 |
|---|---|---|---|
| 01 首次输入 | 一句话 → 展开输入组成 → 逐项介绍 → 工具定义局部展开并收回 | 方向 C 已由用户选作后续视觉基准，清理版已生成并保存 | S01—S04 |
| 02 模型输出请求 | 引入语言模型 → 输入送入 → 生成工具请求 → 展开参数 → 宿主接收 | 十二格预览已生成，待用户审阅 | S05 |
| 03 执行与回流 | 宿主调用转写程序 → 返回结果 → 组织下一次输入 → 再次调用模型 → 给人的回答 | 待制作 | S06—S08 |

还剩两个主镜头。每张板三列四行，整板4:3，每格16:9横幅；背景必须实际不透明黑色，交付前检查文件模式与背景像素。图形身份、配色和局部展开方式延续[清理版基准](../素材/图片/视觉基准/镜头01_首次输入_十二格_清理版.png)。

清理版是视觉风格与布局基准，生图中的代码排版不作为可执行 Schema；字段真源仍是[工具定义](../素材/来源/whisper-mcp/transcribe_audio.schema.json)。正式动画用准确文字重建，环境到录音的连线应表示路径对应，不表示已读取。
