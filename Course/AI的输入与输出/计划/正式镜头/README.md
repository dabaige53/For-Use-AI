# 正式镜头提示词

当前生图与动画设计入口，每个主镜头一个JSON，完整prompt可独立使用。三镜都用十二格演进板；单格16:9，整板4:3，实际视频16:9。图片是构图参考，代码里的文字、字段和连线需准确重建。

1. [01 首次输入](01_首次输入.json)：一句话→输入全貌→逐项局部展开→工具定义→收回。
2. [02 生成识别执行](02_生成识别执行.json)：小型输入→逐步生成调用消息→程序识别→工具执行→返回结果。
3. [03 结果回流与回答](03_结果回流与回答.json)：接收结果→配对→更新输入→第二次调用→回答→两次调用对照。
