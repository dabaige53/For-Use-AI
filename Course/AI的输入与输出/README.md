# AI 的输入与输出

当前版本：2026-09-16 R2，正文与连续图形设计可审阅。主线是用户首次提出整理本地录音的任务，宿主组织输入、模型生成工具请求、外部执行、结果回流、再次调用并回答。

## 阅读入口

1. [正文](文章/正文.md)：内容真源，已统一为本地录音案例。
2. [连续镜头逻辑](计划/本地录音_分镜与生图提示词.md)：三个主镜头下的八个动作段，约 180 秒的设计预算，逐段列出问题、概念、动作、局部文字、旁白和衔接。
3. [图形动作设计](计划/图形动作设计.md)：固定舞台、稳定对象与局部展开规则。
4. [文字阅读页](文章/图文阅读.html)：正文的静态阅读副本；图形方案在设计文档中，本页不是视频画面预览。
