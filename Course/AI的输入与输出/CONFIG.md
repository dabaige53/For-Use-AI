## 480p 代码制作入口

本次开发范围为三镜静音动画与 480p 视频验证；不包含正式配音。工程见 `代码/manim/README.md`。初始化使用 `./init.sh`，依赖锁定 ManimGL 提交 fafa083a4fb274bba9cabde0b6e2f50ba6da0622，Python 3.11、FFmpeg、Pango 和可用 OpenGL context；中文字体 PingFang SC，可通过 `AI_IO_FONT` 替换为本机中文字体。没有使用 LaTeX。

在工程目录运行 `uv run python render.py --scene all --quality 480p`；480p 为 854×480，默认 30fps，`--fps` 可调整；`--quality 1080p` 支持后续导出。`--output` 指定新的输出目录，已有目录拒绝覆盖。输出包括独立镜头、整片、时间线、日志和完整解码报告。首次安装失败检查网络及 uv；渲染失败读取对应日志并检查 OpenGL/Pango/字体；编码失败检查 FFmpeg。

输入只读课程 Schema 和源码，写入本课程临时渲染目录；没有读取教学路径对应文件，不执行转写、保存纪要或发布。缓存与视频可重建，保留原图和既有未提交资料。
