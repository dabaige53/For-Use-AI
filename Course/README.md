## 目录约定

```text
Course/
├── README.md
├── 视频制作规范.md
└── <课程名称>/
    ├── README.md
    ├── CONFIG.md
    ├── 文章/
    ├── 计划/
    └── 素材/
```

公开仓库不收录归档、临时渲染、交付媒体、工作日志、外部原文镜像或包含本机绝对路径的文件。
