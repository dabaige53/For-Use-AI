# Illustrations

黑白简笔线条插画，白底，全部为 3:2（1536 × 1024）。只能按原比例缩放，不能裁掉人物的头、手势和关键道具。两位固定角色：戴眼镜、穿黑色上衣的女同事，以及穿白衬衫的男同事。新增插画时沿用同样的画法、线条粗细和角色造型。

- `paris-everyday.png` / `paris-on-moon.png`：同一构图的埃菲尔铁塔，一张在城市街道，一张在月球表面。用于 `TwoColumnCompare`。
- `review-01-first-draft.png`、`review-02-fix-facts.png`、`review-03-fix-tone.png`：女同事递交、指出问题并认可男同事的修改，机位相同。用于 `StoryPanels`；第 3 张也用于 `DiscussionList`。
- `quiz-01-confident.png`（自信讲解）、`quiz-02-wondering.png`（看着几份文件思考）、`quiz-03-verifying.png`（对照资料核实）。用于 `QuizColumns`。
