# Icons

Lucide 线性图标（v0.460.0，ISC 许可），线宽 1.5。素材文件的描边颜色写死为 `ink`（#1f2737），因为 `<img>` 无法继承文字颜色；在页面里内联使用时，改成跟随所在位置的颜色（横栏、附件卡用 `brand-blue`，动作条用 `apricot-strong`）。

- `file-spreadsheet` / `file-text` / `mail`：表格、文档、邮件附件和文档卡片。
- `clipboard-list`：共同任务、对照检查。
- `eye`（读一遍）、`lightbulb`（想一想）、`pencil-line`（改写练习）：学员动作条。
- `message-square`：输入框的发送按钮。
- `paperclip`、`table-2`、`user-round`、`bot`：备用。头像不用图标，直接写“你 / AI”。

需要更多图标时，从同一版本的 Lucide 里选，不要混用其他图标库。
