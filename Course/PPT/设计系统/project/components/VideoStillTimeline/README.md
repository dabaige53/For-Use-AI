# VideoStillTimeline

视频静帧页：左侧 16:9 静帧和分段进度条，右侧两行要点。

**何时用**：引用外部讲解视频的某一段。

## 需要提供

- 静帧图片、时间码、分段名、两行要点。

## 规则

- 静帧 744 × 418.5，位于 (54, 148.75)。
- 进度条 `progress-height` 4.5，底轨 `hairline`，已播放部分 `brand-blue`，当前位置是一个小圆点。
- 刻度下方写分段名，当前分段用 `label`（蓝色粗体），其余用 `caption`。
- 右侧两行要点用 `block-title`，第二行改为 `brand-blue`；下方用 `caption` 标注“原视频静帧”。
- 这是静帧，不能写成可播放的视频。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
