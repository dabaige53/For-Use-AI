# PromptProbability

输入与预测页：两栏原文面板，下方是选项和小概率条。

**何时用**：展示“给 AI 的全部内容”以及它更可能怎样回复。

## 需要提供

- 两段原文、三个选项、两组百分比。

## 规则

- 栏标题 `block-title`，下面的蓝色标签 `label` 写“输入给 AI 的全部内容”。
- 原文放在 `panel` 面板里，无边框，圆角 `radius-card`，每行一句 `body`。
- 问题 `question`：“AI 更可能怎样回复？”。
- 选项 A–C 用 `body`；小概率条 67.5 × `bar-height` 6，填充 `brand-blue`；百分比 `caption` 右对齐。
- 两栏的选项文字完全一致，只有比例不同，便于学员对照。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
