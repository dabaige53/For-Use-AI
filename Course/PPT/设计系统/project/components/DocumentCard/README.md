# DocumentCard

文档卡片：把邮件、通知、周报这类成品画成一张“纸”。

**何时用**：AI 的产出本身是一份文档，或者页面需要展示发出去的样子时。

## 需要提供

- 文档类型和标题（显示在标题栏）。
- 邮件需要收件人和主题；周报、纪要需要分段标签。
- 正文。

## 规则

- 白底，`radius-window` 12，带 `shadow-object`，和对话窗口同级。
- 标题栏：Lucide 图标（mail、file-text）+ 类型名。
- 分段文档左侧放蓝色段落名（完成 / 问题 / 下周计划），右侧放内容。
- 正文 21pt `ink`，行高 32。
