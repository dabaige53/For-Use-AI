# StoryPanels

三格分镜页：同一场景的三个阶段，每格下方是评分和改写。

**何时用**：用连续的故事说明反馈怎样一步步改进结果。

## 需要提供

- 任务说明、三格标题、三张插画、每格的评分与改写。

## 规则

- 三栏各宽 348，起点 54 / 453 / 852。
- 格标题：序号 `label` + `brand-blue`，标题 `block-title`。
- 插画 348 × 232（3:2），三格保持同样的机位、尺寸和人物位置，只改变动作和表情。
- 评分 `question` + `apricot-strong`（−3、＋1），后面跟一句原因；“新人改为”用 `caption`，改写内容用 `body` + `ink`。
- 页面顶部用一行 `body` 说明任务。
