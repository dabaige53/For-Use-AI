# CaseSingle

单案例页：对话窗口是主角，右侧解读栏说明这次回复为什么合格。

**何时用**：展示改进后的结果，或者需要逐条检查 AI 产出的时候。

## 需要提供

- 标题、案例进度。
- 上一轮缩略（这个案例的第二页需要）。
- 一轮对话，AI 回复可以带产出标签。
- 2–3 条检查项，每条一个标题和一句说明。

## 规则

- 窗口约占 60%（宽 700），解读栏宽 410，两者间距约 36。
- 解读栏顶部是蓝色小标题（如“对照检查”）加图标，下面是白底细边框的解读卡，每张卡前有 ①②③。
- 引线从 AI 气泡右边缘的对应行出发，连到解读卡；每条引线对应一个高亮或标签。
- 同一案例的两页，窗口位置和大小完全一致。
