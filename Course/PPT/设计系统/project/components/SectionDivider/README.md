# SectionDivider

章节扉页：大号蓝色章节号、章节名、一句问题，右侧露出照片。

**何时用**：每章开头一页。

## 需要提供

- 章节号、章节名、本章要回答的问题。

## 规则

- 章节号 `numeral-section`（180pt，`brand-blue`），位置 (46.5, 153.75)。
- 章节名 `statement`（54pt），下方是橙色短横线和一句 `body` 问题。
- 照片上叠一层白色渐变：左侧 0–33% 纯白，到 62% 处完全透明。
- 没有页面标题，也没有页码；左下角保留“AI × WORK”。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
