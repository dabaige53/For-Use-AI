# ChatWindow

对话窗口：模拟一次和 AI 的对话，用户在右、AI 在左。

**何时用**：页面里出现任何“你对 AI 说 / AI 回答”的内容时都用它。

## 需要提供

- 每条消息的文字（`chat` 21pt，`ink`），一页最多 1–2 轮，单个气泡约 80 字以内。
- 需要时：AI 气泡顶部的产出标签（修改稿、整理结果…）；标题栏右侧的“输入 A / B”或“正在输入”。
- 讲提示词写法时：输入框里的那句话。

## 规则

- 窗口是白底，`border` 1px 描边，`radius-window` 12，带 `shadow-object`。标题栏 40 高，蓝色圆点加“AI 助手”。
- 用户：`blue-tint` 气泡靠右，头像“你”。AI：白底描边气泡靠左，头像“AI”是 `brand-blue` 底白字。
- 气泡最宽 75%；内容是表格、公式或多段文字时可以放宽到整行（`is-wide`）。
- 窗口高度按内容来定，不要留大块空白；并排的两个窗口高度保持一致。
