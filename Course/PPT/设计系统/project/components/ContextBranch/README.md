# ContextBranch

分叉对照页：一句话分成两种背景，各自下方是一组横向概率条。

**何时用**：说明加入背景信息后，AI 回答的可能性分布如何变化。

## 需要提供

- 共同的句子、两种背景各自的说明和三档比例。

## 规则

- 顶部句子 `block-title` 居中；用 `text-muted` 1.5 线宽的斜线分到两侧，再用短竖箭头接到条形图。
- 左侧用 `brand-blue`，右侧用 `apricot-strong`；背景名称 30pt 粗体，满足大号文字的对比度要求。
- 大概率条：底轨 `tint-blue` 330 × `bar-height-lg` 21，填充按比例；标签 21pt 粗体 `ink`。
- 每侧最多 3 档，最后一档写“其他”。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
