# CaseCompare

A/B 对照案例页：同一份材料、两种问法，比较 AI 的两个回复。

**何时用**：案例的重点是“多说了哪些条件，结果就不一样”的时候。

## 需要提供

- 标题（这一页的结论）、案例进度。
- 共同材料：一句描述 + 迷你表格。
- 两组对话（输入 A / B 各一轮）。
- 1–2 条标注和一个学员动作问题。

## 规则

- 共同材料横栏在顶部（146 起，约 104 高），迷你表格靠右。
- 两个窗口各宽 561，间距 24，高度相同；标题栏右侧写“输入 A / 输入 B”。
- 两边结构必须完全一致，只有内容不同，方便学员横向对照。
- 差别用高亮加行内编号标出来，说明写在 B 窗口下方；左下是学员动作条。
