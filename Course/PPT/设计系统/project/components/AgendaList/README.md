# AgendaList

目录页：左侧三个带圆圈序号的章节，右侧一张照片。

**何时用**：放在开场之后，列出全课三章。

## 需要提供

- 三章的序号、标题、问句。
- 右侧照片（默认 `Photography/notebook-desk.jpg`）。

## 规则

- 序号圆圈直径 `agenda-dot` 54，描边 `border` 0.75，序号 22.5pt 粗体 `brand-blue`。
- 每章标题 `block-title`（`ink`），下面一行问句 `body`；每项的纵向步长约 `space-section` 142.5。
- 照片区 (678, 157.5) 522 × 470.25，按比例裁切填满。
- 章节标题一律用 `ink`、无下划线（原稿第 02、03 项被显示成超链接色，属于错误）。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
