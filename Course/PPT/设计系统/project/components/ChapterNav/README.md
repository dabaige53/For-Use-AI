# ChapterNav

章节导航页：淡色章节号、章节名、跳转链接和三段式面包屑。

**何时用**：一章结束、需要跳到另一份完整课件时使用。

## 需要提供

- 章节号、章节名、问题、链接文字。

## 规则

- 左侧 615 宽的纯白区，加 202.5 宽的白色渐变过渡到照片。
- 章节号用 `numeral-section`，颜色改为 `tint-blue`，表示这里是导航而不是开始讲这一章。
- 跳转链接 `body-strong` + `brand-blue`，末尾加“→”。
- 面包屑“了解它 / 看清它 / 用好它”中当前章节加粗为 `ink`，斜杠前后各留两个全角空格。
