# QuizColumns

三栏测验页：每栏一道题，题号、插画、题干和选项。

**何时用**：一章结束时检查理解。

## 需要提供

- 三道题，每题的插画、题干、选项，以及单选或多选。

## 规则

- 栏间用 `hairline` 竖线分开（x = 423.75 和 823.5）。
- 题号 `block-title` + `apricot-strong`（30pt 粗体）。
- 插画 283.5 × 189（3:2），在栏内居中。
- 题干 `question`，两行；选项 `body`，前面是 `option-mark` 24：单选用圆圈，多选用方框，描边 `text-muted` 1.5。
- 选项步长 48。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
