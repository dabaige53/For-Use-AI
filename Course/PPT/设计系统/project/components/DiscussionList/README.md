# DiscussionList

讨论题页：左侧三道带淡色大序号的问题，右侧一张插画。

**何时用**：开场时请学员分享自己的使用经验。

## 需要提供

- 三道题、一张插画。

## 规则

- 序号 `numeral-index`（60pt），平时用 `tint-blue`；最想让学员展开的一项改用 `tint-apricot`，标题同时改为 `apricot-strong`。
- 标题 `block-title`，问句 `body` + `text-muted`。
- 每题纵向步长 144（`space-section`）。
- 插画 510 × 340（3:2）。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
