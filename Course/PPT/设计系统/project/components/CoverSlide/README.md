# CoverSlide

课程封面：全幅山顶照片，左上两行主标题，左下写讲师信息。

**何时用**：整套课件的第 1 页。

## 需要提供

- 照片：`Photography/summit-cover.png`，铺满画布，人物在右侧。
- 标题、副标题、讲师、单位与日期。

## 规则

- 主标题两行（`cover-title`，`ink`），起点 (66, 130.5) 和 (66, 201.75)。
- 短横线比普通页长：36 × 2.25，位置 (67.5, 293.25)。
- 副标题写三段式（`cover-subtitle`，`text-body`）。
- 讲师姓名 `body-strong`、单位和日期 `caption`，都用白色放在照片暗部；左下角保留白色“AI × WORK”。
