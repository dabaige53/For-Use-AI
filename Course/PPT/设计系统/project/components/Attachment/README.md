# Attachment

附件卡和迷你表格：把用户提供的文件和 AI 产出的表格画出来。

**何时用**：案例需要用到材料时，例如考勤表、销售表、上周周报、会议纪要。

## 需要提供

- 文件名、一行摘要（行数、字数、关键列）。
- 迷你表格：列字母、行号、3–5 行能看清的数据，其余行用“…”。
- AI 产出的表格：表头和若干行。

## 规则

- 附件卡：36 的方形图标底（`blue-soft`）+ 文件名（18pt 粗体）+ 摘要（15pt `text-muted`），白底细边框，`radius-card`。
- 迷你表格模仿 Excel：列字母和行号用 `panel` 底，网格线用 `hairline`；要强调的单元格用 `highlight`。
- AI 产出的表格不画竖线：浅色表头加细横线，18pt。
- 表格内容必须来自案例材料，不要编造数据。
