# StepFlow

五步流程页：上排三步、下排两步，用细箭头连接。

**何时用**：讲解一个循环过程（看到前文 → 预测 → 对照 → 调整 → 再练）。

## 需要提供

- 五个步骤名与说明、一个示例、一个思考题。

## 规则

- 每步：序号 `caption` + `brand-blue`，步骤名 `block-title`，下方说明 `body` 或 `caption`。
- 关键结果放大成 39pt 粗体：预测结果用 `brand-blue`，正确答案用 `apricot-strong`。
- 箭头 `connector` 1.5 线宽；从第 3 步折回第 4 步时，先向下，再向左，最后向下。
- 底部用“想一想”标签（`label`）加一句 `question` 作为互动。
