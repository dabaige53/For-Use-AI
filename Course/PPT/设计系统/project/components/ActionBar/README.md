# ActionBar

横栏：共同材料或任务、上一轮缩略、学员动作条。

**何时用**：页面顶部交代情境，或页面底部请学员做一件事。

## 需要提供

- 共同材料或任务的标签和一句描述（可以附迷你表格）。
- 上一轮：你和 AI 各一句，过长时用省略号截断。
- 学员动作：动词开头（读一遍、想一想、选一选）+ 一个问题。

## 规则

- 共同材料或任务：`blue-soft` 底，蓝色图标和蓝色标签，正文 `ink`。
- 上一轮：`panel` 底，18pt，单行。
- 学员动作条：`apricot-tint` 底，动词用 `apricot-strong`，问题用 `ink` 粗体 21pt；一页只出现一处。
