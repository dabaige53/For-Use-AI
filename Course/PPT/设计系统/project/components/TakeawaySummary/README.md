# TakeawaySummary

收获总结页：左侧淡色大“3”加三个问题，右侧两个蓝色大数字，底部一句口号。

**何时用**：开场说明学员能带走什么，或在结尾回顾。

## 需要提供

- 三个问题、两组数字与说明、一句口号。

## 规则

- 背景数字 `numeral-ghost`（285pt，`tint-blue`）放在左侧，作为图形，不承载文字信息。
- “理解 三个问题”用 45pt 粗体，“理解”两字用 `brand-blue`。
- 三行“名称 | 说明”中间用 `hairline` 短竖线分隔。
- 右侧大数字 `numeral-hero`（121.5pt，`brand-blue`），旁边是 `block-title` 和一句说明。
- 底部用横线隔开，`slogan`“把 AI 当同事”中的“同事”用 `apricot-strong`，后面接一句 `lead`。
