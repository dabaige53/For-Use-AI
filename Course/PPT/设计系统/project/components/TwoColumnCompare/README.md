# TwoColumnCompare

左右对照页：两栏输入，中间一条竖线，每栏下方配一张插画。

**何时用**：让学员比较两次输入只差一句话时，结果有什么不同。

## 需要提供

- 两栏标题、每栏的输入原文、两张同一构图的插画（例如 `paris-everyday` / `paris-on-moon`）。

## 规则

- 两栏各宽 522，竖线 `hairline` 位于 x = 627，高 420。
- 栏标题 `block-title`；输入原文用 `body`。
- 右栏新增的那句话需要突出：用 `ink` 粗体加 `highlight` 高亮（暖色不用于小号文字）。
- 插画 315 × 210（3:2），在栏内居中。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
