# InstructorProfile

讲师介绍页：头像字卡、个人信息、四张统计卡片和一年用量热力图。

**何时用**：课程开头介绍讲师。

## 需要提供

- 姓名、单位、三条介绍、四个指标、每日用量数据。

## 规则

- 头像字卡 165 × 198，`blue-soft` 底、`radius-card` 圆角，中间放 82.5pt 姓氏，下方一句 13.5pt 标语。
- 信息行：左侧 `label` 标签，右侧 `body` 内容。
- 统计卡片 196.5 × 75，白底，`border` 0.75 描边，`radius-card`；上方 `caption` 写指标名，下方 30pt 常规体写数值。
- 热力图放在 1146 × 285 的描边容器里，色块按 `heat-0` 到 `heat-4` 分五档，图例写“少 … 多”。
- 在卡片上方用 `meta` 写统计口径。

页面不放页码，也不放“AI × WORK”页脚（封面、扉页、导航页除外）；坐标单位是 pt（画布 1254 × 705.75）。
