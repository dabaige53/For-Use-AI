# Annotation

高亮和标注：指出对话里哪一句、哪一个词起了作用。

**何时用**：任何需要学员注意某个具体差别的地方。一页最多 3 条。

## 需要提供

- 要高亮的原文片段。
- 每条标注的短标题和一句说明（“说清交付：要公式，还要知道写在哪一格”）。

## 规则

- 高亮用 `highlight` 淡底，上面是 `ink` 字，不加下划线、不加粗整句。
- 引线从气泡边缘出发，`connector` 1.5 线宽，线头是 3px 小圆点，拐一个直角连到说明。多条引线按从上到下错开拐点，不能交叉。
- 编号徽章 22 圆形，`apricot-strong` 底白字。
- 空间不够时不画引线，改为在高亮后面放徽章，说明写在窗口下方。
- 标注说明这一处“做对了什么”或“缺了什么”，不要重复原文。
