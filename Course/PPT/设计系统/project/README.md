用于制作新版《和 AI 做同事》课程 PPT。整体风格：冷灰白底，白色的对话窗口和文档像放在桌面上的实物，柔和的蓝色负责结构，暖杏色只用来提醒学员做事。内容要完整、看得见：对话画成对话窗口，材料画成表格，结论用高亮和标注指出来，不把文字直接堆在页面上。

## 画布与单位

- 画布 **1254 × 705.75**（`slide-width` × `slide-height`），约 16:9。本系统所有数值都按 **1px = 1pt** 记录：在 PowerPoint 中直接按 pt 填写；做 HTML 时按 1254 宽搭建，再整体缩放。
- 左右页边距 `space-page-x` = 54，内容区宽 1146。标题顶边在 54，标题下有一条暖杏色短横线（`rule-width` 30 × `rule-height` 2.25，顶边在 122.25），正文从 `space-content-top` = 146 开始。最下方的元素离底边至少 `space-page-bottom` = 36。
- **不放页码，也不放页脚。** “AI × WORK”只出现在封面、章节扉页和导航页。案例页在右上角放进度标签（“案例 3 / 8”）。

## 怎样设计一页

- **一页一个判断。** 标题直接写结论或问题：“说清你能用的工具”“把标准写成能核对的要求”。不写“概述”“案例”这类栏目名。
- **文字要放在合适的形状里。** 形状反映内容本来的样子：AI 对话放进对话窗口（`ChatWindow`），邮件、通知、周报放进文档卡片（`DocumentCard`），表格和文件画成迷你表格或附件卡（`Attachment`），任务和材料放进横栏，学员要做的事放进动作条（`ActionBar`）。白底上只直接放标题和一句说明。容器按内容需要来选，没有固定清单。
- **阅读顺序按内容决定。** 每页用三条检查：3 秒内能找到主角（最大、最醒目的那个框）；视线顺着内容自然移动，不需要来回跳；每个框都有存在的理由，删掉任何一个都会让信息不完整。
- **信息要完整。** 案例要把材料画出来：表格只画能看清的 3–5 行，其余用“…”表示。关键差别用高亮和标注（`Annotation`）指出来，不让学员自己找。
- **控制数量。** 一页最多 1–2 轮对话，单个气泡约 80 字以内，标注最多 3 条。放不下就分页，不缩小字号。下一页顶部用“上一轮”缩略条接住上一页。
- **案例页不放总结框。** 案例页只画案例本身：对话、材料、①② 解读卡，最多再加一个提问动作条。句式、方法名复述、“保留 / 去掉”对照、“带进新对话”这类附注写进讲师备注；句式只集中放在“8 个句式”汇总页。删掉附注后重新排版，让窗口和解读卡填满版面。
- **按讲课顺序逐步显示**（只在演示模式生效）：讲到哪块，点出哪块。互动页先露出问题或空槽，学员猜完再点出答案；对比页先出 A 再出 B；流程页按步骤出；金句页第二句后出。被答案替换的提问可以在同一次点击淡出。每次点击只出一块内容，只用淡入、上浮或弹出；讲师备注开头写“点击顺序”。封面、扉页、导航页、视频页、房间分镜页不加；跨页的多轮对话和前后变化仍靠分页表现。

## 文字书写

- **页面上的字是课件，不是讲稿。** 完整的解释、比喻和口语化的说法写进讲师备注，页面只放标题、关键词和短语。
- **标题直接写结论。** 用陈述句，不制造反转和对仗，不写“不是……而是……”“比……更好”“但它……”这类句式。讲原理时可以用“术语：结论”，例如“预训练：从海量文本中学会续写”“人类反馈：倾向于诚实的回答”。
- **标签要短。** 图上的标签 2–10 个字；说明最多一句，放不下就删字，不换成两行长句。
- **用规范术语。** 写“预训练、人类反馈、参数、预测、续写、标注员”，不写“接话、答法、拧一点、照样接得很顺”这类口语比喻。
- **主语写清楚。** 少用“它”，写明是“模型”“AI”还是“标注员”。
- **判断写结果。** 写“编造了日期和地点”，不写“标注员：不选。日期和酒店都是编的。”
- **对应关系用箭头。** 类比和映射写成“学生 → AI 模型”“评分 → 参数调整依据”，不用等号，也不写成句子。

| 不这样写 | 这样写 |
| --- | --- |
| 读得多，所以没读过的也照样接 | 预训练：从海量文本中学会续写 |
| 猜偏了，拧一点 | 预测有误，调整参数 |
| 人来挑：老实说不知道，比编得像更好 | 人类反馈：倾向于诚实的回答 |
| 高分的答法，越练越常用 | 高分的回答方式被保留 |

## 颜色

- **底色和实物**：页面是 `canvas`（冷灰白）。窗口、文档、气泡、卡片用 `surface`（白）。公式块、表头、缩略条用 `panel`。
- **文字三级**：`ink` 用于标题、气泡正文、标注；`text-body` 用于说明和材料描述；`text-muted` 用于窗口标题栏、图注、表格列号。`text-muted` 不能放在 `blue-tint` 或 `highlight` 上。
- **蓝色表示结构和身份**：`brand-blue` 用于 AI 头像、A/B 和“输入 A / B”、序号、AI 产出标签、横栏标签。`blue-tint` 用于用户气泡，`blue-soft` 用于共同材料或任务横栏。
- **暖杏色表示“请学员注意”**：`apricot-tint` 是动作条的底色，一页只出现一处；`highlight` 是荧光笔式高亮，上面放 `ink` 文字；`apricot-strong` 用于 ①②③ 徽章、题号和 30pt 以上的暖色粗体字；`apricot` 只用于短横线、条形图填充等图形，不作文字颜色。
- **对照不靠颜色区分**：两侧对照靠位置和 A/B 区分，不用“一边蓝一边橙”。
- 线条：`hairline` 用于分隔线和表格横线；`border` 是窗口、气泡、附件卡的 1px 描边；`connector` 用于标注引线和流程箭头（1.5 线宽）。
- 所有文字搭配都达到 4.5:1（大号粗体 3:1），具体数值写在各颜色的用途说明里。

## 字体与字号

- 中文统一用 **PingFang SC**（苹方，macOS 自带）；Windows 回退到“微软雅黑”，网页回退到 Noto Sans SC。公式和代码用 `mono`（SF Mono / Menlo / Consolas）。
- 层级（单位 pt）：
  - 54 用于金句和章节名，39 用于页面标题，30 用于栏目标题，24 用于题干。
  - **21 用于正文、气泡和动作条，是投屏时的最小正文字号。**
  - 18 用于标注、解读栏和标签。
  - 15 用于窗口标题栏和表格；14 只用于标签和头像这类不需要细读的字。
- 只用两种粗细：标题、标签、动作条用粗体，其余用常规。

## 界面模拟

- **对话窗口**：中性通用样式，不模仿任何具体产品。标题栏高 `window-head` 40，左侧是蓝色圆点加“AI 助手”，右侧可以写“输入 A”“正在输入”。头像为 `avatar` 32 的圆形，写“你 / AI”。用户气泡用 `blue-tint`、靠右；AI 气泡白底加 `border` 描边、靠左。气泡最宽 `bubble-max` 75%，不带尖角，圆角 `radius-card` 8。需要说明产出类型时，在 AI 气泡顶部加胶囊标签（修改稿、整理结果、流程草案）。
- **输入框**：只在讲“怎么写提示词”的页面出现，把要讲的那句话放在输入框里，后面跟一个蓝色光标。
- **阴影**：只有对话窗口和文档卡片带 `shadow-object`，其余元素都是平的，只用细边框。
- **圆角**：窗口和文档用 `radius-window` 12；气泡、卡片、横栏用 `radius-card` 8；公式块和迷你表格用 `radius-sm` 6；标签、头像、徽章用 `radius-pill`。
- **表格**：材料表格画成迷你 Excel，带列字母和行号、浅色网格；AI 产出的表格用浅色表头加细横线，不画竖线。
- **公式和代码**：等宽字体，放在 `panel` 底的小块里；句子中间的单元格地址用行内样式。

## 高亮与标注

- 关键句用 `highlight` 淡底高亮，不加下划线、不改字色、不把整句加粗。
- 标注有两种做法，每页选一种：
  - **引线**：从气泡边缘引出 `connector` 细线，线头是小圆点，连到旁边的 ①②③ 说明或解读卡。多条引线按从上到下错开拐点，不能交叉。
  - **行内编号**：空间不够时，在高亮后面直接放 ①② 徽章，说明写在窗口下方。
- 标注写“这里说清了什么”，不要重复原文。

## 版式

| 这一页要讲 | 版式 |
| --- | --- |
| 同一任务的两种问法 | `CaseCompare`：顶部共同材料横栏（附迷你表格），两个结构完全一致的对话窗口并排，下方是标注和动作条 |
| 一个案例的结果与检查 | `CaseSingle`：对话窗口约占 60%，右侧约 40% 是解读栏，用引线连到 ①②③ 解读卡 |
| 开场、分章、收束 | `CoverSlide`、`AgendaList`、`SectionDivider`、`ChapterNav`、`KeyStatement` |
| 原理与过程 | `StepFlow`、`ContextBranch`、`VideoStillTimeline`：示意图至少占页面宽度的 60%，文字只作图上的标签 |
| 互动与检查 | `DiscussionList`、`StoryPanels`、`QuizColumns` |
| 数据 | `TakeawaySummary`、`InstructorProfile` |

- 一个案例分成两页时，两页的窗口位置和大小完全一致，翻页时只有内容在变。
- 案例总览用大小不一的卡片（bento-grid），每张写图标、任务名和这个案例解决的问题。
- 讲调用流程时固定使用“你 / 应用 / 模型”三条泳道，同一角色在每页都出现在同一位置。
- 互动页：选项是带字母徽章的卡片；排序题画出空槽；改写练习做成带栏目和横线的纸质表单。
- 金句和过渡页：纯文字、大字号、大量留白，不配图。
- 原稿沿用下来的版式（原理、互动、数据三组）已经换成新配色，并去掉了页码；用到时按上面的原则补上容器和标注。

## 图片

- 三类图各有分工：人和场景用插画，原理和过程用 SVG 示意图，对话、文档、邮件用界面模拟。
- 插画统一用黑白简笔线条，内容按页面需要设计，不固定角色。不用大眼日漫、彩色卡通、3D 或特效。插画放在白底圆角框里。
- 图片只能按原比例缩放，不能压扁、拉宽，也不能裁掉头部、手势和关键物件。题目、对白、标签保留为可编辑文字，不画进图里。
- 照片只用于封面、章节扉页和导航页。三章扉页共用 `summit-cover.png`，左侧叠白色渐变，文字放在渐变上。

## 图标

- 使用 **Lucide** 线性图标，线宽 1.5，尺寸 `icon` 20（动作条中用 24）。常用图标在 `Icons` 素材组里。
- 图标颜色跟着所在位置：横栏和附件卡用 `brand-blue`，动作条用 `apricot-strong`。不用彩色图标或 emoji。
