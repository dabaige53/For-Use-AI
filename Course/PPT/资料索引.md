## 地形案例讲述要点

每组先展示输入与路径，再比较另一种表达带来的变化，最后落到下一次可以怎样提问或反馈。

| 案例 | 观察重点 |
|---|---|
| 语义漂移 | 当前行动是否偏离初始目标；及时重申任务 |
| 特征纠缠 | 一个词带出哪些连带特征；分辨需要保留和调整的部分 |
| 显式配平 | 明确边界与限制，调整被过度强化的要求 |
| 隐式提纯 | 用集中、清晰的语义表达方向，减少属性堆叠 |
| 案例好于说明 | 用具体案例呈现难以单靠抽象词说明的标准 |
| 引导采样与回滚 | 通过比较提炼有效表达，再回到合适节点尝试 |
| 先推理后结论 | 展开判断依据后形成结论，并核验依据是否成立 |
| 语义退火 | 先探索可能性，再按目标和约束收敛行动 |

## 四象限与知识管理的关系

散点图描述行动的投入与对齐依据；四种认知状态描述我们对知识的认识。两者配合使用，不把四种认知状态直接等同于散点图的四个象限。

- **知道自己知道**：调用已有知识或标准，在执行中检验。
- **知道自己不知道**：指出具体缺口，通过查证或试验补齐。
- **不知道自己知道**：通过案例比较与回顾，把隐性经验说清楚。
- **不知道自己不知道**：借助实际使用、反例和外部反馈发现盲点。
